# 🔢 Matrix Operations in C

## 📖 Overview
This project implements matrix addition and matrix multiplication using two-dimensional arrays and functions.

## ✨ Features
- Matrix Addition
- Matrix Multiplication
- Dynamic Matrix Input
- Modular Function-Based Design

## 🛠️ Technologies Used
- C Programming
- 2D Arrays
- Functions
- Nested Loops

## 🚀 How to Run
1. Compile the program:
   gcc matrix_operations.c -o matrix

2. Run the executable:
   ./matrix
